## Important
This GitHub-Pages build uses browser `localStorage` as a functional prototype.
Admin changes are immediately visible when the recruit logs in in the SAME browser/profile.
For real synchronization between Sgt Carter's PC and a recruit's PC, connect the portal to a backend/database
(e.g. Supabase/Firebase/custom API). Do not use real passwords in this static demo because the JavaScript is public.
