# Notebook font

MRPD Notebook is a Latin/punctuation subset of Kalam Regular and Bold by Indian Type Foundry, renamed for this modified distribution. The font is distributed under the SIL Open Font License in `Kalam-OFL.txt`.

Original sources
- https://github.com/google/fonts/tree/main/ofl/kalam
- https://raw.githubusercontent.com/google/fonts/main/ofl/kalam/Kalam-Regular.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/kalam/Kalam-Bold.ttf

The website loads the WOFF files locally when exporting a case. No external font service is contacted.
